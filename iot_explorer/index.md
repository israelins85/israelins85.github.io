# IoT Explorer

A desktop inspector for IoT protocol traffic: MQTT, CoAP, OPC UA, Modbus,
BACnet, LoRaWAN, AMQP 1.0, MQTT-SN, HTTP Webhook, Sparkplug B, HTTP Polling,
Siemens S7, EtherNet/IP, SNMP and KNX/IP.
