# GitHunks

A focused Git client for the Mac: stage by hunk or by line, resolve conflicts side by side, read history on a commit graph and see who wrote every line.

Um cliente Git direto ao ponto para Mac: prepare por bloco ou por linha, resolva conflitos lado a lado, leia o histórico num grafo de submissões e veja a autoria de cada linha.

## English

### What it does

- **History you can read:** commit graph with branch and tag chips, search, an "Uncommitted changes" row, full commit details, and blame for any file with moved-line detection.
- **Stage precisely:** stage, unstage or discard whole files, single hunks or only the lines you select; flat list or folder tree; diff options for context, whitespace and invisible characters; side-by-side image diffs.
- **Resolve conflicts in the app:** pick ours, theirs or both for each chunk, edit the result by hand, undo and redo, with word-level highlights.
- **Everyday Git:** pull, push and fetch with progress you can cancel; branches, tags, merge, rebase, cherry-pick, revert, reset, stash and Git Flow; submodules, subtrees and Git LFS; GPG signing, commit templates and per-repository identities.
- **Many repositories, one window:** groups and sub-groups, one tab per open repository, ahead/behind counts, drag and drop to add folders.

### Requirements and price

macOS 12 Monterey or later. GitHunks is free for one repository. GitHunks Pro, a single one-time in-app purchase (no subscription), unlocks unlimited repositories and groups.

### Privacy

No accounts, no analytics, no telemetry. Credentials are handled by Git and your macOS Keychain. See the [Privacy Policy](privacy/).

## Português

### O que faz

- **Um histórico fácil de ler:** grafo de submissões com rótulos de ramos e etiquetas, pesquisa, a linha "Alterações pendentes", detalhes completos e autoria de qualquer arquivo com detecção de linhas movidas.

- **Resolva conflitos no app:** escolha a versão local, a do outro lado ou as duas para cada trecho, edite o resultado à mão, desfaça e refaça, com destaque por palavra.
- **O Git do dia a dia:** receber, enviar e buscar com progresso que dá para cancelar; ramos, etiquetas, mesclar, rebase, colher submissão, reverter, redefinir, reservar alterações e Git Flow; submódulos, subárvores e Git LFS; assinatura GPG, modelos de mensagem e identidades por repositório.

### Frequently asked questions

- **What does the free plan include?** Everything in the app, for one registered repository. GitHunks Pro unlocks unlimited repositories and groups.
- **I have more than one repository and the app shows a lock screen.** The free plan allows one repository. Remove repositories from the list (this does not delete anything on disk) until one is left, or unlock GitHunks Pro.
- **How do I restore my purchase on another Mac?** Open Settings (Cmd+,) > General > GitHunks Pro > Restore purchases, signed in with the same Apple ID.
- **Why does GitHunks ask for my home folder on first launch?** The Git tools it runs read your global Git settings, SSH keys and credential helper from your home folder, and GitHunks keeps its small settings in `~/.githunks`. Choose your home folder in the system panel.
- **Where are my passwords stored?** GitHunks does not store them. Git stores them in your credential helper (the macOS Keychain).
- **Does GitHunks send my code or usage data anywhere?** No. See the [Privacy Policy](privacy/).

### Perguntas frequentes

- **O que o plano gratuito inclui?** Todo o app, para um repositório cadastrado. O GitHunks Pro libera repositórios e grupos ilimitados.
- **Tenho mais de um repositório e o app mostra uma tela de bloqueio.** O plano gratuito permite um repositório. Remova repositórios da lista (isso não apaga nada do disco) até sobrar um, ou desbloqueie o GitHunks Pro.
- **Como restauro minha compra em outro Mac?** Abra Configurações (Cmd+,) > Geral > GitHunks Pro > Restaurar compras, com o mesmo Apple ID.
- **Por que o GitHunks pede a minha pasta pessoal no primeiro uso?** As ferramentas Git que ele executa leem as configurações globais do Git, as chaves SSH e o credential helper da sua pasta pessoal, e o GitHunks guarda suas poucas configurações em `~/.githunks`. Escolha a sua pasta pessoal na janela do sistema.
- **Onde ficam as minhas senhas?** O GitHunks não as guarda. O Git as guarda no seu credential helper (o Keychain do macOS).
- **O GitHunks envia meu código ou dados de uso para algum lugar?** Não. Veja a [Política de Privacidade](privacy/).
