# GitHunks Privacy Policy / Política de Privacidade

_Last updated / Última atualização: 2026-10-22_

## English

GitHunks is a Git client for the Mac. It works on your computer and does not collect, transmit or sell any personal data. It has no account system, no analytics and no telemetry.

### What stays on your Mac

GitHunks keeps its own files in the folder `~/.githunks`: the list of repositories and open tabs (`state.json`), your preferences (`settings.json`) and, if you bought GitHunks Pro, a cached copy of the purchase receipt signed by Apple (`pro.json`). These files never leave your Mac, and you can delete them at any time.

### Your repositories

GitHunks reads the repositories you add, locally, to show history, differences and status. Your code is not uploaded anywhere by GitHunks. When you run network operations (clone, fetch, pull, push), the Git tools bundled with the app connect directly to the Git servers (remotes) that you configured, exactly as Git would from the command line. GitHunks does not see or store that traffic.

### Credentials

If a remote asks for a user name and password or token, GitHunks passes what you type to Git, which stores it in your configured credential helper (on macOS, the Keychain). GitHunks does not store credentials itself. SSH keys stay in your `~/.ssh` folder and are used only by the bundled OpenSSH.

### Purchases

GitHunks Pro is a one-time in-app purchase sold and processed by Apple through the Mac App Store. The application asks StoreKit whether the purchase exists and stores Apple's signed answer locally so it can start offline. Payment details are handled by Apple and are never visible to the application. Apple's privacy policy applies to that processing: https://www.apple.com/legal/privacy/

### Children

GitHunks is a developer tool and is not directed to children.

### Changes

Changes to this policy are published on this page with a new date. If GitHunks ever collects data of any kind, this policy and the App Store privacy information will be updated before that release.

## Português

O GitHunks é um cliente Git para Mac. Ele funciona no seu computador e não coleta, transmite nem vende dados pessoais. Não tem contas, análises de uso nem telemetria.

### O que fica no seu Mac

O GitHunks guarda os próprios arquivos na pasta `~/.githunks`: a lista de repositórios e abas abertas (`state.json`), as suas preferências (`settings.json`) e, se você comprou o GitHunks Pro, uma cópia do comprovante da compra assinado pela Apple (`pro.json`). Esses arquivos nunca saem do seu Mac e você pode apagá-los quando quiser.

### Seus repositórios

O GitHunks lê, localmente, os repositórios que você adiciona para mostrar histórico, diferenças e estado. O seu código não é enviado a lugar nenhum pelo GitHunks. Quando você executa operações de rede (clonar, buscar, receber, enviar), as ferramentas Git que acompanham o app se conectam diretamente aos servidores Git (remotos) que você configurou, exatamente como o Git faria na linha de comando. O GitHunks não vê nem guarda esse tráfego.

### Credenciais

Se um remoto pedir usuário e senha ou token, o GitHunks entrega o que você digitar ao Git, que o guarda no credential helper configurado (no macOS, o Keychain). O GitHunks não guarda credenciais. As chaves SSH ficam na sua pasta `~/.ssh` e são usadas apenas pelo OpenSSH que acompanha o app.

### Compras

O GitHunks Pro é uma compra única no app, vendida e processada pela Apple na Mac App Store. O aplicativo pergunta ao StoreKit se a compra existe e guarda localmente a resposta assinada pela Apple para poder abrir offline. Os dados de pagamento ficam com a Apple e nunca são vistos pelo aplicativo. A política de privacidade da Apple se aplica a esse processamento: https://www.apple.com/legal/privacy/

### Crianças

O GitHunks é uma ferramenta para desenvolvedores e não é direcionado a crianças.

### Alterações

As alterações desta política são publicadas nesta página com uma nova data. Se o GitHunks algum dia coletar dados de qualquer tipo, esta política e as informações de privacidade da App Store serão atualizadas antes dessa versão.
